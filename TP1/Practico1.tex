\section{Línea de comandos}

La gran mayoría de las distribuciones de Linux proveen acceso a una interfaz basada en \textbf{texto}.

En general, escribimos un comando, apretamos \lstinline!Enter!, se ejecuta y muestra el resultado.

Podemos abrir una terminal abriendo el menú de aplicaciones y seleccionando ``Terminal'', o simplemente apretando \lstinline!Ctrl+Alt+T!.

Esto abre \lstinline!gnome-terminal! que es un emulador de terminal.

Dentro vamos a ver una linea similar a:

\begin{lstlisting}[language=bash]
ubuntu@ubuntu:~$
\end{lstlisting}

Esta se llama ``prompt'' y singifica que esta a la espera de un comando.

Se puede intepretar de la siguiente manera:

\begin{notebox}
\textcolor{blue}{\texttt{ubuntu}} $\leftarrow$ nombre de usuario\\
\texttt{ubuntu}\textcolor{blue}{\texttt{\#}} $\leftarrow$ se lee ``at'' y significa ``en''\\
\texttt{ubuntu@}\textcolor{blue}{\texttt{ubuntu}} $\leftarrow$ el nombre de la maquina\\
\texttt{ubuntu@ubuntu}\textcolor{blue}{\texttt{:}} $\leftarrow$ separador\\
\texttt{ubuntu@ubuntu:}\textcolor{blue}{\texttt{\textasciitilde}} $\leftarrow$ Carpeta actual\\
\texttt{ubuntu@ubuntu:\textasciitilde}\textcolor{blue}{\texttt{\$}} $\leftarrow$ Nos indica que estamos en modo usuario; \texttt{\#} significa \texttt{root}.
\par\smallskip
El símbolo \texttt{\#} indica que el usuario es \texttt{root}, con privilegios administrativos. Esto no significa que el proceso esté ejecutándose en ring 0 ni en modo kernel: los rings son niveles de privilegio de la CPU, mientras que \texttt{root} es una cuenta del sistema operativo.
\end{notebox}

\section{Carpetas y archivos}

Los archivos dentro del sistema de archivos de linux tienen un ``path'' o ``ruta'' en el que estan ubicados.

Estos ``paths'' tienen unas nomenclaturas especiales:

\begin{notebox}
Si el ``path'' empieza con \textcolor{orange}{``\texttt{/}''} entonces es un path \textcolor{orange}{``absoluto''}.\\
Si el ``path'' empieza con un nombre entonces es un path \textcolor{green!45!black}{``relativo''} a la carpeta actual.\\
El caracter \textcolor{purple}{``\texttt{\textasciitilde}''} es especial y significa el \textcolor{purple}{``home directory''} o ``directorio casa'' para el usuario actual.\\
El caracter \textcolor{red}{``\texttt{.}''} es especial y es una referencia a la carpeta actual.\\
El conjunto \textcolor{teal}{``\texttt{..}''} es especial y significa la \textcolor{teal}{``carpeta padre de''}.
\end{notebox}

\section{Descriptores de archivos}

Un descriptor de archivo ``file descriptor'' es un número entero no negativo que utiliza el sistema operativo para identificar de forma única un archivo abierto (entre otras cosas).

Por defecto, casi todos los programas se inician automáticamente con tres canales de comunicación asignados a valores enteros fijos:

\begin{itemize}[nosep]
  \item 0 (\texttt{stdin}): Entrada estándar
  \item 1 (\texttt{stdout}): Salida estándar
  \item 2 (\texttt{stderr}): Error estándar
\end{itemize}

Si abrimos un archivo usando la llamada al sistema \lstinline!open!, es posible que se nos asigne el descriptor ``3''.

\subsection{Algunos comandos}

Un comando util es \lstinline!pwd! - ``Print working directory''. Esto muestra como resultado la carpeta actual que tenemos abierta (``cwd'' - Current Working Directory). Es posible ejecutar sin argumentos.

\begin{lstlisting}[language=bash]
ubuntu@ubuntu:~$ pwd
/home/ubuntu
ubuntu@ubuntu:~$
\end{lstlisting}

Otro comando conveniente es \lstinline!ls!. - ``List directory contents''. Lista las carpetas y archivos que se encuentan en el ``cwd''.

\begin{lstlisting}[language=bash]
ubuntu@ubuntu:~$ ls

ubuntu@ubuntu:~$
\end{lstlisting}

Es posible cambiar de carpeta con \lstinline!cd! - ``Change directory''.

\begin{lstlisting}[language=bash]
ubuntu@ubuntu:~$ cd Pictures/
ubuntu@ubuntu:~/Pictures$ pwd
/home/ubuntu/Pictures
ubuntu@ubuntu:~/Pictures$ ls
Screenshots
ubuntu@ubuntu:~/Pictures$
\end{lstlisting}

Otro detalle interesante a notar es que acabo de mostrar un archivo del \lstinline!procfs!.

\begin{infobox}
En muchos sistemas operativos tipo UNIX se utiliza el sistema de archivos \lstinline!proc! (proc filesystem o \lstinline!procfs!), que es un sistema de archivos, generado dinámicamente, que muestra información de procesos. Es un sistema de archivos que no tiene relación con un dispositivo de almacenamiento.

Está implementado en el núcleo del sistema operativo y permite llevar a «espacio de usuario» datos del núcleo y de los procesos, que, sin la ayuda de \lstinline!procfs!, sería casi imposible accederlos.

Este sistema de archivos está montado normalmente en el directorio \lstinline!/proc! y, dado que no contiene archivos reales, no consume espacio de almacenamiento.

Como es un sistema de archivos es posible navegarlo con \lstinline!cd! y \lstinline!ls!.

\end{infobox}

\subsection{APT: administrador de paquetes}

APT (\textit{Advanced Package Tool}) permite instalar, actualizar y eliminar programas en distribuciones basadas en Debian, como Ubuntu.

La información sobre los paquetes disponibles se actualiza con:

\begin{lstlisting}[language=bash]
ubuntu@ubuntu:~$ sudo apt update
\end{lstlisting}

Este comando descarga la información más reciente desde los repositorios configurados. No instala ni actualiza programas.

Para instalar un paquete usamos:

\begin{lstlisting}[language=bash]
ubuntu@ubuntu:~$ sudo apt install tree
\end{lstlisting}

Para eliminarlo:

\begin{lstlisting}[language=bash]
ubuntu@ubuntu:~$ sudo apt remove tree
\end{lstlisting}

Podemos buscar paquetes por nombre o descripción:

\begin{lstlisting}[language=bash]
ubuntu@ubuntu:~$ apt search tree
\end{lstlisting}

La opción \lstinline!sudo! ejecuta el comando con permisos administrativos, necesarios porque la instalación modifica directorios y archivos protegidos del sistema.

Una secuencia habitual para instalar software es:

\begin{lstlisting}[language=bash]
ubuntu@ubuntu:~$ sudo apt update
ubuntu@ubuntu:~$ sudo apt install gcc
\end{lstlisting}

\begin{infobox}
\texttt{apt update} actualiza el índice de paquetes. \texttt{apt install} instala un paquete usando ese índice. Son operaciones distintas.
\end{infobox}

\section{Llamadas a sistema, ``syscalls''}

Podemos utilizar el programa \lstinline!strace! (system call trace) que sigue la traza a las llamadas a sistema y las señales de un proceso, interceptándolas, registrándolas y mostrándolas por pantalla (stderr, standard error).

Cada línea mostrada contiene el nombre de la llamada a sistema, seguido por sus argumentos en paréntesis y sus valores retornados.

Por ejemplo, si ejecutáramos el comando

\begin{lstlisting}[language=bash]
ubuntu@ubuntu:~$ cat /dev/null
ubuntu@ubuntu:~$
\end{lstlisting}

Debería mostrarnos el contenido de un archivo (de contenido nulo en este caso) pero que al seguirle el rastro a las llamadas a sistema que efectúa con el comando:

\begin{lstlisting}[language=bash]
ubuntu@ubuntu:~$ strace cat /dev/null
execve("/usr/bin/cat", ["cat", "/dev/null"], 0x7ffe9d9161f8 /* 57 vars */) = 0
[...]
statx(AT_FDCWD, "/dev/null", AT_STATX_SYNC_AS_STAT, STATX_ALL, {stx_mask=STATX_ALL|STATX_MNT_ID, stx_attributes=0, stx_mode=S_IFCHR|0666, stx_size=0, ...}) = 0
openat(AT_FDCWD, "/dev/null", O_RDONLY|O_CLOEXEC) = 3
[...]
read(3, "", 65536)                      = 0
close(3)                                = 0
[...]
exit_group(0)                           = ?
\end{lstlisting}

Nos muestra las sucesivas llamadas al sistema que va efectuando el proceso \lstinline!cat!.

Podemos destacar entre sus llamadas al sistema la que carga el ejecutable en memoria \lstinline!execve("/bin/cat"...! y la que efectivamente abre el archivo para ver su contenido \lstinline!openat("/dev/null")!.

Podemos observar que el resultado de la syscall \lstinline!openat! es ``3''. Esto significa que el sistema operativo abrio el archivo y le asigno el descriptor de archivos 3. Luego vemos como se utiliza este descriptor para interactuar con el archivo: se llama \lstinline!read(3, ...! y \lstinline!close(3)!.

\begin{infobox}
Podemos probar también con un programa simple como \lstinline!pwd! y observar que logra su objetivo primordial haciendo una llamada a la función \lstinline!getcwd!.
\end{infobox}

\section{Mensajes del kernel: \texttt{dmesg}}

El comando \lstinline!dmesg! muestra mensajes del kernel almacenados en el ring buffer. Es útil para investigar el arranque del sistema, dispositivos, drivers y errores del kernel.

\begin{lstlisting}[language=bash]
ubuntu@ubuntu:~$ sudo dmesg
ubuntu@ubuntu:~$ sudo dmesg -H
ubuntu@ubuntu:~$ sudo dmesg -k
ubuntu@ubuntu:~$ sudo dmesg -H -k
\end{lstlisting}

La opción \lstinline!-H! muestra la salida en un formato más legible para humanos. La opción \lstinline!-k! selecciona los mensajes del kernel. Las opciones se pueden combinar.

\begin{infobox}
Comparar las salidas y buscar mensajes relacionados con dispositivos USB, discos o la interfaz de red.
\end{infobox}

La línea \lstinline!#include <stdio.h>! es una directiva para el preprocesador del compilador.

Esta directiva le indica al compilador que debe incluir el contenido del archivo de cabeceras llamado \lstinline!stdio.h! (standard input and output) dentro del programa.

Este archivo contiene definiciones de funciones tales como \lstinline!scanf()! y \lstinline!printf()!. (Por ser parte de la libreria estandar, tambien funciona \lstinline!man scanf!!)

La función de biblioteca \lstinline!printf()! envía texto formateado a la pantalla.

\section{Permisos de archivos}

En Linux, cada archivo tiene permisos para tres grupos de usuarios:

\begin{itemize}[nosep]
  \item propietario (\texttt{user} o \texttt{u}),
  \item grupo propietario (\texttt{group} o \texttt{g}),
  \item resto de usuarios (\texttt{others} o \texttt{o}).
\end{itemize}

Cada grupo puede tener permisos de lectura, escritura y ejecución:

\begin{itemize}[nosep]
  \item \texttt{r}: leer el contenido,
  \item \texttt{w}: modificar el contenido,
  \item \texttt{x}: ejecutar el archivo.
\end{itemize}

Podemos observarlos usando:

\inputcode[language=bash]{../examples/tp1/hello/permissions-symbolic.session}

Los primeros diez caracteres representan el tipo de archivo y sus permisos. El primer carácter indica el tipo; por ejemplo, \texttt{-} representa un archivo regular. Los siguientes nueve caracteres se agrupan en propietario, grupo y otros:

\begin{lstlisting}[language=bash]
-rwx r-- r--
 u   g   o
\end{lstlisting}

También es posible expresar permisos usando números. Los valores son:

\begin{itemize}[nosep]
  \item lectura: $4$,
  \item escritura: $2$,
  \item ejecución: $1$.
\end{itemize}

Por ejemplo, \texttt{chmod 755 hello.py} asigna permisos de lectura, escritura y ejecución al propietario, y permisos de lectura y ejecución al grupo y al resto:

\inputcode[language=bash]{../examples/tp1/hello/permissions-numeric.session}

Alternativamente es posible ejecutarlo directamente usando python: \lstinline!python3 hello.py!
